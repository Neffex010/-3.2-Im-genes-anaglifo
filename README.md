# 👓 Visor Estereoscópico Anaglifo 3D

Una aplicación web interactiva y responsiva diseñada para visualizar una galería de 15 fotografías estereoscópicas utilizando la técnica de anaglifo (rojo/cian). Este proyecto demuestra la integración de diseño de interfaces modernas, manipulación del DOM y manejo de APIs del navegador.

## 🚀 Enlaces del Proyecto

* **Sitio Web en Vivo (GitHub Pages):** [Haz clic aquí para ver la galería](https://neffex010.github.io/-3.2-Im-genes-anaglifo/)
* **Imágenes Originales:** [Carpeta en Google Drive](https://drive.google.com/drive/folders/1j5oZlfe6s0bEoTWBH40JeED51878o6TO?usp=sharing)

## ✨ Características Principales

* **Galería Interactiva:** Carrusel fluido con 15 fotografías en formato anaglifo.
* **Navegación Accesible:** Control del carrusel mediante clics, indicadores táctiles o atajos de teclado (flechas `←` y `→`).
* **Experiencia Inmersiva:** Integración de la *Fullscreen API* para expandir la galería a pantalla completa con un solo clic.
* **Diseño UI/UX Avanzado:** 
  * Efecto de fondo desenfocado inteligente para rellenar los espacios laterales de las fotografías verticales sin perder inmersión.
  * Estilo "Glassmorphism" y paleta de colores oscura optimizada para resaltar el contraste 3D.
* **Modal de Asistencia:** Ventana emergente integrada con instrucciones de visualización para el usuario final.
* **100% Responsivo:** Adaptabilidad total a pantallas de dispositivos móviles, tablets y computadoras de escritorio.

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Variables globales, filtros de desenfoque (`backdrop-filter`, `blur`), y diseño responsivo.
* **JavaScript (Vanilla):** Lógica del visualizador, eventos de teclado y manejo de la API de Pantalla Completa.
* **Bootstrap 5:** Framework frontend para la estructuración del Navbar, Carrusel y Modales rápidos.

## 🕶️ Instrucciones de Uso

Para disfrutar correctamente del efecto de profundidad en esta galería, el usuario necesita:
1. Un par de **gafas anaglifo**.
2. Colocar el lente **Rojo en el ojo izquierdo** y el lente **Cian (azul) en el derecho**.
3. Mantener una distancia de aproximadamente 50-70 cm de la pantalla con el brillo al máximo.
